# 红果短剧 · 桌面客户端(Electron 封装壳)

一个 Windows 桌面客户端,把**红果短剧官方网页版**(https://hongguoduanju.com/)包装成原生应用。

> 说明:所有内容(视频、广告、登录策略)全部来自红果官方页面,本程序只是一个"壳",不抓取、不修改、不存储任何平台数据,播放体验与浏览器打开官网一致。

## 功能

**基础**
- 原生窗口,关闭时缩到系统托盘,托盘右键可真正退出
- **F11** 沉浸全屏刷剧;`Ctrl+R` 刷新 / `Ctrl+=` `Ctrl+-` `Ctrl+0` 缩放
- 记住窗口位置、大小、最大化/全屏状态
- 单实例:重复启动会唤起已有窗口
- 站内链接在窗口内打开,站外链接自动走系统浏览器
- 断网时显示友好的错误页,可一键重试

**v1.1 新增**
- **老板键 `Ctrl+Shift+B`**(全局生效):一键隐藏窗口并自动暂停播放,再按一次唤回
- **小窗置顶**(430×760 竖屏比例):边干活边刷剧
- **观看历史**:自动记录在官网看过的剧(仅存本地 JSON,不上传),托盘"最近看过"一键直达,可清空
- **开机自启**:托盘菜单勾选即可

## 使用

```bash
npm install   # 首次
npm start     # 启动
```

## 打包成 exe 安装包

```bash
npm install   # 会补装 electron-builder
npm run dist  # 产物在 dist/ 目录(NSIS 安装包 + win-unpacked 免安装版)
```

> 如果打包时报 winCodeSign 符号链接权限错误:用 7-Zip 把 `winCodeSign-2.6.0.7z` 解压到
> `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0\`(忽略两个 macOS 符号链接报错)即可。

## 设计边界(有意不做)

不做下载、弹幕、去广告、多源聚合等功能——那类实现依赖逆向红果私有接口,属于未授权访问,也是同类开源项目频繁"取源失效"的根源。本项目只做合规的桌面壳。
